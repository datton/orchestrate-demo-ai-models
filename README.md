# ai-models.demo.orchestrate.ca

Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript, no build step.

**Text only.** By the operator's brief there are no images, SVG, icons, canvas or emoji art. Typography and CSS carry the design. `assets/` stays empty.

## Structure
- `index.html`: one scroll-story page, eight chapters (hero, what is a model, LLMs, diffusion, GANs and VAEs, other types, how they compare, closing)
- `css/tokens.css`: colours, type, spacing (Designer)
- `css/layout.css`: header, nav, scroll shell (UI/UX)
- `css/site.css`: base styles (Lead Developer)
- `js/nav.js`, `js/app.js`: behaviour

## Run locally
Open `index.html` in a browser.
